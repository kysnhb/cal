# 웹 0.1.3: 19.5:9 모바일 가로 화면

## 적용

- 전투 화면의 세로 기준 640을 유지하고 가로 공간을 약 1386.67로 확장했습니다. CSS 비율뿐 아니라 원본 카메라·월드 표시 범위도 넓혔습니다. 캐릭터와 버튼은 같은 비율로 표시됩니다.
- 전투의 이동 버튼·체력은 왼쪽, 행동 버튼은 오른쪽, 타이머는 중앙으로 배치합니다. iOS/Android 브라우저가 제공하는 안전 영역을 읽어 노치·홈 영역만큼 HUD와 터치 판정을 함께 이동합니다.
- 전투 배경을 반복해 빈 곳을 채우고, 메뉴 배경은 비율을 유지해 화면을 덮습니다. 글자가 포함된 튜토리얼 이미지는 중앙에 온전히 표시하고 양옆에 기존 배경을 표시합니다.
- 무기·목표·일시정지 메뉴의 위치와 터치 판정을 함께 중앙으로 이동했습니다. 목표 화면에서도 전투 HUD의 아이콘·횟수 배치를 유지합니다.
- 양쪽 조작 영역 사이의 빈 공간은 보이지 않는 버튼을 누르지 않도록 제외합니다. 일시정지가 포인터를 누르는 순간 열리더라도 손가락 해제를 누락하지 않습니다.
- 모바일 시작·세로 회전 안내·조작법·저장 기능과 최종 키 배치를 유지했습니다. 앱의 그래픽 리소스와 Android/Windows 화면 크기는 이번 웹 전용 수정에서 변경하지 않았습니다.
- 배포 시 JS·Wasm·게임 데이터 각각의 해시를 요청 URL에 붙입니다. 기존 접속자의 캐시에 남은 이전 실행 파일과 새 HTML이 섞이지 않게 합니다.

## 검증

Chrome 153 / WebGL 2 / 별도 브라우저 저장소에서 검사했습니다. 휴대폰 CSS 화면 크기와 안전 영역을 모사한 검사이며 실물 iPhone Safari 검사는 아닙니다.

| Galaxy S25/S26 계열 크기 780×360 | 780×360 | 여백 없이 19.5:9 |

- `tests/wide_view_test.cpp`: 안전 영역별 투영·역변환, 중앙 빈 공간 입력 제외, 메뉴 전환 직후 포인터 해제. 통과.
- `tests/web_wide.cjs`: 메인·모드·튜토리얼·스테이지·무기 4페이지·목표 화면, iPhone 크기의 좌우 59px/하단 21px 안전 영역, 조작 버튼 10개 위치, 앉기·이동·점프 동시 터치, 일시정지·조작법 복귀, Galaxy 크기로 변경. 통과. 페이지 오류 0건.
- 실제 월드 너비는 1386으로 확인했습니다. 이동 검사에서 캐릭터 월드 좌표 1600→2417, 카메라 1108→1697, 화면 내 캐릭터 x=720으로 넓어진 화면의 중앙 근처를 추적했습니다.
- `tests/web_mobile.cjs`: 전체 화면·가로 고정 요청, 거절 시 회전 안내, 세로 전환 시 정지와 입력 해제, 가로 복귀, 조작법의 터치/키보드 탭, 짧은 화면. 통과.
- `tests/web_controls.cjs`: A/D/W/S/K/L/O/Z/Space/M 키 안내와 실제 입력, 필살기 차감, 도움말 입력 차단과 일시정지 복귀. 통과. 결과는 함께 보관한 `controls.json`을 확인합니다.
- `tests/web_smoke.cjs`: 동시 터치·입력 해제·저장 복원·오디오·무기 메뉴. 통과. 결과는 함께 보관한 `web-smoke.json`을 확인합니다.
- 배포 포맷 검수: JS·Wasm·게임 데이터를 각각 올바른 해시 URL로 요청하는지 확인하고, 준비 완료→가로 전환→전투→일시정지→조작법까지 실행했습니다. 통과. `asset-loading.json`에 요청 주소와 결과가 있습니다.

화면과 JSON 증거는 `web_wide_20260930/`에 있습니다. 빌드는 `scripts/verify_web_export.py`로 배포 파일의 해시를 확인합니다. 물리 기기의 Safari·자동 회전·노치 최종 검수와 전체 스테이지 완주 검사는 포함하지 않습니다.
