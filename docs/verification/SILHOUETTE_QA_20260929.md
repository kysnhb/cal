# R15 / 1.0.6 외곽광 검수

## 적용

몸체는 원본 검은 스틱 실루엣, 머리는 기존 모자의 검은 윤곽입니다. 아군/인질은 푸른 외곽광, 적은 붉은 외곽광입니다. 진영 슬롯 경계(0x32c134)와 AI 종류(각 actor의 0x8dd3c)를 읽으며 공격·행동 데이터는 쓰지 않습니다. 몸체 질감·추가 폭 증가·망토는 없습니다.

외곽광은 원본 알파에서 한 번 생성한 거리 기반 텍스처입니다. 캐릭터별 빛을 모든 본체 조각 뒤에 놓습니다. 원래 회전·좌우 반전·논리 크기를 유지하고 패딩 오프셋만 보정합니다. GPU 부품당 잔광 스프라이트 1회가 추가되며 프레임마다 이미지를 생성하지 않습니다. PMA 블렌딩과 복귀 후 LINEAR 필터 복구를 사용합니다.

## 확인 결과

- Android 1.0.6 / code7, Windows C++ 컴파일·링크 성공.
- 원본 마스크 131개 바이트 대조, 골격·회전·동작 데이터 해시 유지. 변경은 표시 코드에 한정.
- 실루엣 검사: 원본 알파/관절 크기, 좌우 반전 패딩, 테두리의 바깥 감쇠, PMA, 아군·인질·적 분류 통과.
- 기존 상점/광고 1,000회 반복 및 UI 글자/프레임 검사 통과.
- Windows와 Android 전투·메뉴·도움말 캡처 성공. 실제 화면에서 검은 몸체, 모자 윤곽, 파랑/빨강 외곽광 및 관절 겹침 확인.
- Android 정상 속도 전투 녹화와 3초 HOME/복귀 확인. 같은 프로세스 유지. 강제 GL context loss 검사는 아님.

## 범위

MuMu Android15 x86_64에서 ARM64 번역 실행했습니다. 실물 ARM64 휴대전화의 성능/발열과 전체 스테이지·특수 변신·탈것 조합은 미검증입니다. 인질 분류는 원래 initPimg/COMAI 코드와 단위 검사로 확인했으며 이번 캡처에서는 인질 구조 장면까지 재현하지 않았습니다. 기존 일부 특수 캐릭터/탈것의 고유 스프라이트는 그대로입니다. 자동 논리 입력과 물리 터치 검사는 구분합니다. 사용자 아트 수락을 자동 테스트 통과로 대신하지 않습니다.
