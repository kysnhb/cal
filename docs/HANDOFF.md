# 프로젝트 인수인계 / R15

2026-09-29 `프로젝트복원_01` 작업을 인수하고 그래픽·프로그램 세션의 수정을 통합했습니다. 현재 코드·이미지 기준은 R15 / 1.0.6입니다. [현재 화면](art/stickman_redesign_20260929/index.html), [다른 PC 설정](SETUP.md)을 먼저 확인하세요.

## 반영 내용

- 상점·쿠폰의 ARM64 문자열/포인터 처리, 한국어 경로 저장, 광고 미연동 시 실패·닫힘 복귀 수정.
- 모바일 기준 HP/재화 글자 크기, 무기 슬롯·설명·가격 프레임, 메뉴·상점·입력·결과창의 새 UX와 원본 코드 충돌 수정.
- 고딕 배경, 움직이는 구름과 제한된 효과, Pretendard 적용.
- 캐릭터는 원작 부품 마스크 131개와 골격·액션 데이터를 보존. 인간형 재타기팅과 망토 제거. 모자 윤곽·검은 몸체와 파랑/빨강 진영 외곽광으로 수정.
- LA PNG를 L,L,L,A로 해석. 캐릭터 부품은 C++에서 4배 밀도로 한번 생성하고 재사용. LINEAR 축소, 원래 피벗과 팔레트·피격 효과 유지.
- 로컬 런타임 헤더 12개를 CMake 의존성에 명시해 이 PC의 깨진 include 출력 접두어 때문에 증분 빌드가 수정 파일을 놓치던 문제 보완.

R10의 단색 스틱맨, R11 금속 가면, R12 주황빛 의상, R13 먹색 광택 후보는 사용자 피드백으로 교체했습니다. R14 무광 의상도 사용자 요청으로 교체했습니다. R15는 원본 몸체 알파를 사용하는 검은 실루엣이며 의상 질감은 사용하지 않습니다. 스타일에 대한 사용자 수락을 자동 검사 통과로 대신하지 않습니다.

게임 속도·공격 판정·피해량·가격·AI·보상을 그래픽 수정 목적으로 변경하지 않았습니다. `recomp/gen`을 복구 도구로 일괄 재생성하지 마세요. 보존용 도구 일부는 별도 원본 역컴파일 자료를 요구합니다.

## 검증과 남은 범위

현재 빌드의 자동/시각 검증 범위는 [검증 보고서](verification/SILHOUETTE_QA_20260929.md)에 기록했습니다. 실물 ARM64 휴대전화 성능·발열, 전체 스테이지 장시간 테스트, 광고·결제 실서비스와 배포 서명은 별도 작업입니다. 개인 세이브 대신 QA용 분리 저장 폴더를 사용했습니다.

현재 저장소는 게임 소스·필수 콘텐츠·빌드 도구·현재 검수 문서만 선별합니다. SDK·캐시·실행본·서명키·개인 설정은 제외했습니다. 원본 프로젝트와 이전 납품본은 삭제하지 않았습니다.
