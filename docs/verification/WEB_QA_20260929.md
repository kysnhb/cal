# 웹 버전 0.1 검수

기준: R15 / 모바일 1.0.6 소스, Axmol 2.11.5, Emscripten 3.1.73. 캐릭터·배경·스테이지 콘텐츠 2,208개는 변경하지 않았습니다.

## 실제 확인

- Windows Chrome에서 내보낸 HTML/JS/Wasm/data 실행.
- GitHub Pages 공개 주소 `https://kysnhb.github.io/cal/`에서도 HTTP 200, 게임 준비 완료, 타이틀 렌더링, JavaScript 오류 0 확인. 검수 브라우저 Chrome 153.0.8010.53.
- 첫 실행 → 일일 보상 → 메인 메뉴 → 모드 → 도움말 → 스테이지 → 무기 4페이지 → 실제 전투 진입.
- PC 키보드 이동·공격, 모바일 터치 이벤트로 이동과 점프 동시 조작.
- 점프 손가락을 뗀 뒤 이동 손가락 유지, 모든 손가락을 뗀 뒤 입력 해제.
- 시작 오버레이와 웹 조작법을 열었을 때 게임 틱 정지, 닫으면 재개.
- 포커스 상실 시 눌린 키 해제.
- 1200×832, 844×390, 390×844 크기에서 원본 3:2 비율 유지. 웹 메뉴가 HP나 전투 버튼을 가리지 않음.
- 실제 `aos5stg.bz` 저장 파일과 `UserDefault.bin`의 설정을 새로고침 후 다시 읽어 대조. 설정은 해시 맵 순서가 바뀔 수 있어 키/값으로 비교.
- 저장된 일일 보상을 새로고침 후 중복 지급하지 않음.
- Web Audio 컨텍스트 `running`, JavaScript page error 0.
- 동일 검사를 Pixel 7 모바일 브라우저 에뮬레이션에서도 통과.
- 위 경로에서 Wasm heap 256MiB. 전체 브라우저/GPU 메모리나 장시간 최고 사용량을 뜻하지 않음.
- 콘텐츠 구조 검사와 스틱맨 원본 크기·마스크·망토 제거 계약 검사 통과.

자동 검수: `tests/web_smoke.cjs`. Playwright를 설치한 환경에서 실행합니다.

```powershell
$env:CHROME_EXECUTABLE='C:/Program Files/Google/Chrome/Application/chrome.exe'
node tests/web_smoke.cjs http://127.0.0.1:8080/ build/web-qa
$env:WEB_MOBILE='1'
node tests/web_smoke.cjs http://127.0.0.1:8080/ build/web-qa-mobile
```

## 범위와 남은 확인

실물 Android/iPhone Safari, 저사양 기기 성능, 모든 스테이지의 엔딩까지 검수한 것은 아닙니다. 이번 결과물은 실제 게임을 실행하는 첫 웹판입니다. 진행 상황은 브라우저별로 저장되며 클라우드 계정 동기화는 없습니다.

첫 다운로드는 기존 고딕 게임 리소스 약 158MB와 실행 코드 약 5.7MB가 필요합니다. 세이브와 내려받은 리소스는 브라우저 저장소를 사용합니다. 불필요한 SDK·디버그 심벌·빌드 캐시·기존 PC/Android 세이브는 배포하지 않습니다.

기존 복원판에서 비활성화한 옛 서버/광고/결제 연결을 새 웹 서비스로 활성화하지 않았습니다.
