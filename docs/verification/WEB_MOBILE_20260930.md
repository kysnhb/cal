# 웹 0.1.2: 모바일 우선·가로 플레이

## 적용한 화면 규칙

- 모바일 시작 화면에서는 제목, 로딩 상태, ‘가로로 게임 시작’, ‘터치 조작법 보기’를 표시합니다. PC 키보드 안내는 모바일 시작 화면에서 숨깁니다.
- 시작 버튼의 사용자 입력 안에서 전체 화면을 요청하고, 그 다음 `screen.orientation.lock('landscape')`를 요청합니다. 요청 실패 시에도 실행 오류 없이 회전 안내로 넘어갑니다.
- 모바일 세로 상태에서는 게임 진행과 입력을 멈춥니다. 가로로 돌리면 복귀하되, 원래 게임 일시정지 메뉴를 열어둔 상태는 보존합니다.
- 화면 위 웹 도구 모음은 모바일에서 제거했습니다. 게임 오른쪽 위 일시정지 메뉴의 ‘조작법’과 ‘전체 화면’으로 접근합니다.
- 원본 960×640(3:2)을 유지합니다. 844×390 가로 화면에서 캔버스는 585×390, 세로 위치 0입니다. 844×320에서는 480×320으로 줄어들며 전체 HUD가 들어갑니다. 노치 안전 영역은 별도로 제외합니다.
- 조작법은 모바일 터치 안내를 먼저 보여주며 키보드 탭도 제공합니다. 짧은 가로 화면에서는 터치 배치와 설명을 나란히 표시합니다.

## 검증

Chrome 153 / Pixel 7 브라우저 에뮬레이션, WebGL 2, 별도 임시 브라우저 프로필로 검사했습니다.

- `tests/web_mobile.cjs`: 로딩 중 조작법을 열어도 게임 준비 완료, 세로/가로 시작 버튼 접근, 전체 화면 요청의 사용자 입력 연결, 가로 방향 요청, 두 API가 거절됐을 때의 회전 안내, 세로 상태에서 게임 정지, 가로 복귀, 누르던 터치 해제, 게임 내 일시정지 버튼, 조작법 기본 탭·키보드 전환·복귀, 브라우저 주소창으로 높이가 줄어든 화면.
- `tests/web_smoke.cjs` (`WEB_MOBILE=1`): 실제 브라우저 API 경로, 이동·점프 동시 터치, 한 손가락 해제 후 이동 유지, 포커스 상실 시 입력 해제, 도움말 정지·복귀, IndexedDB 저장 후 새로고침 복원, 일일 보상 중복 방지, 오디오 실행. 통과.
- `tests/web_controls.cjs`: A/D/W/S/K/L/O/Z/Space/M 안내 및 주요 실제 입력, 필살기 차감, 일시정지 메뉴와 키 설명, 도움말의 게임 입력 차단. 통과.
- 페이지 스크립트 오류 0건. 원본 전투 로직과 그래픽 파일은 이번 수정에서 변경하지 않았습니다.

전체 화면과 가로 방향 고정의 허용 여부는 브라우저/기기에서 결정합니다. 거절 상황은 자동 테스트에서 의도적으로 만들어 검사했습니다. 실물 휴대폰의 자동 회전·노치와 Safari 하드웨어 검사는 포함하지 않습니다. 화면 증거와 테스트 결과는 `web_mobile_20260930/`에 있습니다.
