# 웹 0.1.1: 키보드 안내와 일시정지 화면

최종 요청 이미지의 배치: **A 왼쪽, D 오른쪽, W 점프, S 앉기, K 발차기, L 주먹, O 상황별 행동, Z 무기 변경, Space 필살기, M 일시정지**. 방향키와 Esc는 대체 입력으로 유지합니다.

## 변경

- 시작 화면과 조작법 창에 키보드 모양 안내를 추가했습니다. 안내에서 키를 누르면 해당 키가 빛납니다. 안내와 실제 입력은 같은 키 연결표를 사용합니다.
- 일시정지 메뉴의 SOUND / MAIN MENU 아래에 ‘키 설명’ 버튼을 추가했습니다. 설명을 닫으면 일시정지 메뉴로 복귀합니다.
- 일시정지 모드 13이 전투 모드 11과 같은 표시 배치를 사용하도록 수정했습니다. 앉기 버튼·방향 패드·재화가 일시정지 시 원래 좌표로 튀던 원인입니다. 앉기는 이동 패드 위 중앙에 분리하고 터치 영역과 키 입력 위치도 맞췄습니다.
- 844×390 가로, 390×844 세로에서는 안내를 세로로 스크롤할 수 있습니다. 시작/복귀 버튼에 접근할 수 있으며 가로 넘침이 없습니다.

## 원본 버튼 확인

O는 고정된 ‘큰주먹’이 아닙니다. `bzStateGame__handleEvent.c`의 원작 좌표 x710..850 / y361..499 분기와 `bzStateGame__GameUIImg_0041aa04.c`를 확인했습니다.

- 맨손 전투에서는 일반 주먹/발차기와 별도 동작으로 분기하며 이동·자세에 따라 달라집니다.
- 주변 문/이동 지점, 이용 가능한 장비가 있으면 해당 행동을 우선 처리합니다.
- 무기 종류와 상태에 따라서도 동작이 달라집니다. 화면 아이콘 역시 원본의 문/장비 감지 상태에 따라 교체됩니다.
- 웹은 해당 화면 버튼의 원작 터치 경로에 연결합니다. 문 출입이나 무기별 처리를 별도의 새 공격 로직으로 덮어쓰지 않습니다.

## 검수

- `tests/web_controls.cjs`: A/D 실제 월드 좌표 방향, W 점프, S 앉기, K/L/O 서로 다른 자세, Space 잔여 횟수 1회 감소, M 일시정지, 일시정지 메뉴의 키 설명·복귀, 안내의 입력 차단, 화면 폭 검사.
- `tests/web_smoke.cjs` 모바일 브라우저 에뮬레이션: 이동과 점프의 동시 터치, 한 손가락 해제 후 다른 손가락 유지, 화면 비율, 도움말 정지/복귀, 실제 저장 파일의 재실행 복원, 오디오 확인.
- `ui_text_policy_test.cpp`: 일시정지/전투의 동일한 표시 모드와 상점 문맥 우선순위 회귀 검사 통과. 이 PC의 Visual Studio C++ 도구가 없어 Emscripten으로 테스트를 컴파일한 뒤 Node에서 실행했습니다.
- Chrome 153에서 확인했습니다. 실물 휴대폰과 Safari 검사는 포함하지 않습니다. 문/탑승물의 모든 종류를 실플레이로 순회한 것은 아니며 해당 분기는 원본 코드로 확인했습니다.

화면과 실행 기록은 `web_controls_20260930/`에 보관합니다.
